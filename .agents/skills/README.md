# Skills

This folder is the canonical home for Codex skill instructions in this
repository.

## What belongs here

- One folder per skill
- One `SKILL.md` file per skill
- Repo-specific workflows or guardrails that an agent should load on demand

## What does not belong here

- Executable Python helpers
- Research outputs
- Wrapper scripts for humans

Put executable helpers under `.agents/tools/` instead.
