# Analysis Reporting Contract

Every nontrivial analysis should leave enough evidence for a future researcher or agent to answer:

1. What was the research question?
2. What files were used?
3. What commands were run?
4. What code changed?
5. What outputs were produced?
6. Which results are observed versus inferred?
7. Which claims are report-ready?
8. What remains unresolved?

Use these labels explicitly: **Observed**, **Inferred**, **Assumed**, **Unverified**, and **Blocked**.
